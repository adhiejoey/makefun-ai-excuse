One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

`main.ts` writes that single line to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The excuse turns the usual token excuse on its head: the agent burned all its tokens *planning* how to meet the deadline, leaving none to actually meet it — so the apology itself is the only deliverable that came in under budget.
